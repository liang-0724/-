# 物理治療師國考｜歷屆試題（依考科分類）

資料來源：考選部「考畢試題查詢平臺」（wwwq.moex.gov.tw），105–115 年第一次、第二次專技高考物理治療師考試，共 22 次。
每份試題後面都附上標準答案；考選部有公布更正答案的，一律放更正版（答案標 ＃ 的題目看最下方備註）。

合併版的第一頁是目錄，點「試題 p.xx／答案 p.xx」會直接跳頁；
GoodNotes 左上角的「大綱」也能看到每一年、每一次的書籤。排列是新到舊，最近的考題在最前面。

## 放進 GoodNotes「國考」資料夾（iPad）

1. 把 PDF 存到 iPad 的「檔案」App（從 Claude App 點檔案 →「分享」→「儲存到檔案」，或從 GitHub 下載）。
2. 打開 GoodNotes → 進入「國考」資料夾（沒有的話先按「＋ 新增」→「資料夾」建立）。
3. 在「國考」資料夾裡按「＋ 新增」→「匯入」→ 選剛剛存的 PDF（可以一次多選）。
4. 想要每科一個子資料夾的話：在「國考」裡建好 6 個子資料夾，再把 `單份/` 中對應考科的檔案分別匯入。

也可以在「檔案」App 長按 PDF →「分享」→ 選 GoodNotes →「匯入為新文件」，再選擇「國考」資料夾。

## 重新產生

`scripts/` 裡是下載與整理用的程式（Python 3＋pypdf＋reportlab）：

```bash
python3 scripts/download.py work 115020 115090 ...   # 下載指定考試代碼的試題與答案
python3 scripts/build.py work 國考                    # 依考科整理、合併、加目錄與書籤
```

考試代碼可在考畢試題查詢平臺的下拉選單看到（例如 115020＝115 年第一次、115090＝115 年第二次）。
